# 每日戰略新聞簡報 — 產製規格(SPEC)

> 排程於**每個工作日(週一至週五)台北時間 07:30** 自動執行。每次由一個全新 session
> 讀取本規格與 `briefings/` 內最近數則簡報,做網路研究,產出當日簡報,commit 至分支
> `claude/daily-news-briefing-vh78sn`,並於使用者 Gmail 建立完整全文草稿。

## 涵蓋區間
- **自最近一個完整交易日收盤以來**:美股最近收盤 + 亞洲今晨盤面。
- 遇假日/休市:**明確標註各數據的時點**(哪一日收盤、盤中或前一交易日)。

## 最高指導原則:極致事實準確度
1. **區分事實與預測**:嚴格區分「已發生事實」與「機構預測」。市場報價須為真實交易數據,
   不可用情境推估值代替現價;引用預測須標明**來源機構與前提**。
2. **證據導向**:分析市場衝擊以客觀市場反應(具體漲跌幅、資金流向)佐證,避免主觀推論。
3. **過濾極端值**:爭議數據多源交叉比對,排除缺乏根據的極端預測與煽動性報導。
4. **報價層級**:指數以交易所官方收盤為準;CFD/期貨報價標註來源性質;區分「盤中/收盤」;
   所有價格附時點。凡無可靠成交來源者標「待補/待證實」,**不得以推估值填補**。
5. **羅生門處理**:單一來源或匿名消息標「待證實」;官方說法與報告主張衝突時**並列呈現**,不裁決。

## 輸出結構
- **A. 市場儀表板**(只列數字與漲跌幅,各附時點):美股三大指數、費半/SMH、台股加權與櫃買
  (若已開盤)、KOSPI、日經、USD/TWD、美債 10Y 殖利率、WTI/Brent、金價、VIX。
- **B. 科技、資本與大國博弈**:精選 3–6 條,質重於量。
- **C. 宏觀地緣與全球經濟**:精選 3–6 條。
- **D. 台股連動**:外資買賣超(台/韓)、記憶體與 AI 供應鏈族群異動、對台灣半導體供應鏈的傳導路徑。
- **E. 敘事追蹤(只報增量)**:對延續主線(記憶體循環、板塊輪動、美伊談判、重大供應鏈爭議)
  只更新「與前次相比的變化」,不重複背景。
- **F. 未來 1–7 日催化劑日曆**:已排定財報、經濟數據、政策事件(標台北時間)。
- **G. 校驗附註**:本則來源分歧、單源項目、精確度限制。

## 選題加權(依使用者研究焦點)
- **優先**:半導體全鏈(記憶體現貨/合約價、HBM、先進封裝、PCB 載板、矽晶圓、設備)、
  AI 基礎設施(GPU 供需與租賃/二手價訊號、資料中心與電力、互連、hyperscaler capex)、
  資金流與籌碼(外資動向、槓桿融資、擁擠度訊號如利多出盡/空頭回補)、
  美中科技管制與台灣角色、中國 AI 自主化。
- **降低**:與上述無關的一般企業/消費娛樂新聞,除非具指標意義。

## 去重與追蹤
- 產出前先讀 `briefings/` 內最近 3–5 則(**主要去重依據**),Gmail 既有草稿為輔。
  **已報導過的事實請排除**,除非該事件持續變化、有進度更新,或使用者要求追蹤 → 此時只在 E 段報「增量」。

## 交付
1. **Commit** `briefings/YYYY-MM-DD.md` 至分支 `claude/daily-news-briefing-vh78sn`
   (優先 git push;若本地 git 認證被拒 403,改用 GitHub MCP `push_files` 工具寫入)。
2. 於 **Gmail 建立草稿**(收件人為使用者),主旨含日期。
3. session **最終訊息輸出完整簡報全文**(供排程完成 email 通知帶出內容)。
